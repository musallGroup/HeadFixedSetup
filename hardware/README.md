# Hardware

3D-printable enclosures and PCB design files for the two custom boards used in this setup.

- [`breakout/`](breakout) — Breakout PCB (Altium originals + KiCAD import) and its enclosure
  (box + panels)
- [`touchshaker/`](touchshaker) — Touchshaker PCB (Altium originals + KiCAD import) and its
  enclosure (box + panels)
- [`platform/`](platform) — Animal platform and photodiode holder STLs

See [docs/MANUAL.md](../docs/MANUAL.md) for assembly instructions, wiring diagrams, and how these
parts fit together.
